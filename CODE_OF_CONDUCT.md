# Code of conduct

OntoJourney is an academic and technical collaboration space. Participants are
expected to communicate with respect, evaluate ideas through evidence, credit
contributions, and avoid harassment, discrimination, personal attacks, and
dismissive treatment of interdisciplinary expertise.

Disagreement about a model is resolved through definitions, competency
questions, sources, examples, and validation evidence. Critique the proposal,
not the person presenting it.

The maintainer may edit or remove abusive content, close disruptive
interactions, and restrict participation when necessary. Sensitive concerns
should be raised privately through the maintainer's GitHub profile rather than
posted with personal information in a public issue.
