# Security policy

OntoJourney is a public ontology and static documentation site. It does not
process credentials or personal data.

Report a vulnerability in the website build, release archive, or dependency
configuration through GitHub's private security advisory feature for this
repository. Do not include secrets, private datasets, or personal information
in a public issue.

Conceptual-model errors and data-validation defects are not security reports;
use the structured issue templates for those cases.
