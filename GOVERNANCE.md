# Governance

## Maintainer

Luis Felipe Coimbra Costa is the founding maintainer and release steward for
OntoJourney Core.

## Decision process

Changes are issue-led and evidence-based. The maintainer records whether a
proposal is accepted into the core, assigned to an extension module, deferred,
or not incorporated. Decisions consider public scope, domain evidence,
foundational alignment, compatibility, and validation cost.

## Scope control

New terms require a documented need that cannot be met by clearer
documentation, instance data, or an extension namespace. Infrastructure and
metadata changes do not by themselves justify changes to the conceptual core.

## Releases

Every public release includes source, exchange model, RDF serializations,
SHACL, tests, validation evidence, checksums, citation metadata, and release
notes. Entity IRIs remain stable across compatible releases.
