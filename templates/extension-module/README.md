# OntoJourney extension module template

Use this template when a requirement is relevant to an implementation or
research question but does not belong to the frozen core.

## Module claim

State the domain and the questions the module answers.

## Dependency

Record the compatible OntoJourney Core version and ontology IRI.

## Namespace

Use a namespace controlled by the module owner. Do not mint extension terms in
the OntoJourney Core namespace.

## Required contents

- competency questions;
- definitions and scope boundary;
- OntoUML or RDF source;
- alignment axioms to OntoJourney Core;
- SHACL constraints when required;
- positive and negative examples;
- validation evidence;
- version and license metadata.
