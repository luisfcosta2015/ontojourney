# Competency question proposal

## Question

Write one question in language that a domain specialist can understand.

## Use case

Describe the analysis, comparison, design, or validation task that requires the
answer.

## Expected answer pattern

Give one positive example and, when useful, one case that should not satisfy the
question.

## Current gap

Identify the existing terms and explain why they cannot answer the question.

## Scope assessment

State whether the question belongs to the core or to a separate module.

## Evidence

List the primary domain sources or empirical requirements supporting it.
